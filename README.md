# 🌤️ Dummy Weather App

This is a simple weather application built using **Node.js** and **Express.js** on the backend, with a lightweight **HTML + JavaScript** frontend. The app provides mock weather data for a few predefined cities.

---

## 🚀 Features

- Search weather data by city name  
- Displays temperature, condition, humidity, wind speed, etc.  
- Error handling for unknown cities  
- Clean and minimal UI  
- Backend API setup using Express.js  

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js  
- **Frontend**: HTML, JavaScript (No external libraries or frameworks)  

---
